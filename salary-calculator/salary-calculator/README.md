# 월급 계산기 (8급 전용)

단국대학교의과대학부속병원 8급 실제 임금명세서를 기준으로 만든 계산기입니다.
공용 접속번호로 접속을 제한하고, 로그인은 12시간 후 자동 만료됩니다.
입력값과 결과는 서버에 저장하지 않습니다.

## 계산 기준

- **기본급**: 12호봉 2,211,000원을 기준으로, 확인된 상승분 규칙(호봉이 하나 오를 때마다
  상승분이 1,000원씩 커짐)을 적용해 1~30호봉을 추정했습니다. 12~14호봉만 실제 확인된 값이고
  나머지는 추정치이니 다르면 `salary_table.csv`를 직접 수정하세요.
- **고정수당**: 교통보조비 3만원, 급량비 20만원, 위험수당 3만원, 직무수당 5만원,
  체력단련비 3만원, 가족수당 1인당 1.5만원 — 전부 실제 명세서 값 기준.
- **상여/정근수당**: 4월·10월은 정근수당(1년차 50%, 매년 +5%p, 11년차부터 100% 고정),
  그 외 10개월은 매달 기본급의 100%씩 상여금 (연 1000%).
- **명절수당** 2월·9월 50만원, **여름휴가비** 7월 60만원, **자기계발비** 12월 10만원.
- **시간외근무수당** = 시간외근무시간 × 통상시급 × 1.5

## 공제 입력

- **건강보험료·사학연금**: 월별로 크게 안 변하긴 하지만 정확한 계산식이 복잡해서,
  매달 본인 명세서에 나온 숫자를 그대로 입력하는 방식입니다.
- **소득세**: 근사 누진율로 자동 계산됩니다. 실제 국세청 간이세액표와는 차이가 있을 수 있으니
  참고용으로만 쓰세요. **지방소득세**는 소득세의 10%로 자동 계산됩니다 (실제 데이터로 확인된 비율).
- **식대공제** = 전월식수 × 4,300원 (직접 식수 입력)
- **노동조합비(3만원)/주차비(1만원)**: 체크박스로 포함 여부 선택
- **교원공제 / 동호회비 / 기타공제**: 금액을 직접 입력 (0원이면 미포함)
- **교원공제대출은 개인 대출이라 포함하지 않았습니다.**

## 폴더 구조

```
salary-calculator/
├── app.py              # Flask 앱 (라우팅, 급여 계산 로직)
├── config.py           # 고정수당 금액, 정근수당/상여 규칙, 공제 관련 상수
├── salary_table.csv    # 호봉 -> 기본급 표 (12~14호봉만 실제값, 나머지 추정)
├── generate_table.py   # salary_table.csv를 만든 스크립트 (참고용)
├── requirements.txt
├── Procfile
├── templates/
│   ├── login.html
│   └── index.html
└── static/
    └── style.css
```

## 로컬 실행

```bash
pip install -r requirements.txt
set ACCESS_CODE=원하는6자리
set SECRET_KEY=아무거나-긴-무작위-문자열
python app.py
```
브라우저에서 `http://localhost:5000` 접속.

## Render 배포

1. GitHub 저장소를 만들어 이 폴더를 푸시
2. Render → New → Web Service → 저장소 선택
3. Build Command: `pip install -r requirements.txt` / Start Command: `gunicorn app:app`
4. Environment 탭에서 `ACCESS_CODE`, `SECRET_KEY` 환경변수 설정
5. 배포 후 나오는 링크 공유
